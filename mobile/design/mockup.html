📝 Typography

Font Family:
-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
Headings: 20-28px, Bold (700)
Body Text: 13-15px, Regular (400)
Labels: 11-13px, SemiBold (600)
Captions: 10-12px, Regular (400)

📏 Spacing

Screen padding: 15-20px
Element spacing: 12-15px
Section spacing: 20-25px
Card padding: 12-15px

⚪ Border Radius

Buttons: 8-9px
Cards: 10-11px
Chips/Badges: 16-18px
Phone frame: 28-30px

💡 Shadows

Cards: 0 2px 7-8px rgba(0,0,0,0.09)
Phone: 0 6px 25px rgba(0,0,0,0.18)
Store icons: 0 2px 4px rgba(0,0,0,0.2)

💡 Usage Notes

• Orange (#FF6B35) is the primary action color - use sparingly for CTAs and important UI elements
• Dark Blue (#003B5C) provides trust and professionalism - use for headers and primary text
• In dark mode, swap Dark Blue for White (#FFFFFF) in the logo and text
• Always maintain WCAG AA contrast ratios for accessibility
• Store badge colors should never be modified - they represent real brand identities
